# AutoDataCraft

Portfolio site for [autodatacraft.com](https://autodatacraft.com), built with React and Vite.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deploy to Vercel

Import the GitHub repository into Vercel. Vercel will detect Vite automatically. After deployment, add `autodatacraft.com` and `www.autodatacraft.com` in **Project Settings → Domains**, then follow Vercel's DNS instructions at your registrar.

## Before launch

- Replace the email address in `src/App.jsx` if needed.
- Add real Boncos screenshots and a live demo link when available.
- Add social preview artwork and an `og:image` meta tag.
